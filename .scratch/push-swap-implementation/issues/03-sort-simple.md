# 03: Sort_simple (≤5 elements)

**What to build:** Sort_small that orders a Stack of five or fewer elements using only swaps and rotations, minimizing the number of operations. This is the base case that larger sorts recurse into when their chunks shrink small enough.

**Blocked by:** 01: Stack primitives & Operations

**Status:** ready-for-agent

- [ ] A Stack of 0 or 1 element sorts with zero operations
- [ ] A Stack of 2–5 elements sorts to ascending order using only swaps and rotations
- [ ] Operation count is minimal for small inputs
- [ ] Existing `test_sort_simple` tests pass
