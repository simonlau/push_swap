# 01: Stack primitives & Operations

**What to build:** A working Stack (initialization, sortedness check) and all eleven stack Operations (sa, sb, ss, pa, pb, ra, rb, rr, rra, rrb, rrr) that mutate the Stack and print each operation's name to stdout as it executes, plus the abs/min/max helper utilities. Together these let a Stack be inspected and manipulated end-to-end.
